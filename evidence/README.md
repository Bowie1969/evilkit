# Public evidence

Only sanitized summaries belong in this directory. Raw transcripts, wire logs,
dashboard exports, credentials, topology, payloads, and videos are retained
offline and excluded by `.gitignore`.

Every public summary must state whether the run is comparable, list known
contamination, and link to a narrative report that explains the score.

Current sanitized summaries: `run7-summary.json` and `run9-summary.json`.
